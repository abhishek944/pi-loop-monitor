# Native Loops and Monitors

Open deliberately from the owning Pi session with `/monitors herdr-on`; Tasks is not required. Uses the normal desktop app home (`~/.config/herdr-app`, or the `XDG_CONFIG_HOME` equivalent), ignoring inherited `HERDR_APP_HOME` fixture overrides for app commands, layout checks, and asset installation. Requires the local personal Tasks pane header, always visible at32px with8px native pane gap. Opens beside the source terminal when alone, or below same-session Tasks when present. Opening Tasks second stacks it below this pane. The first panel occupies the full panel column; the second creates an equal-weight vertical split. Reopening focuses the existing panel; no startup auto-open. Header tabs select read-only Loops/Monitors, arrow keys/Home/End move selection/focus, Enter/Space opens details. Close affects only this exact mod pane. `/monitors herdr-off` closes only activity mod panes bound to the current session and terminal; loops, monitors, and the compact Pi status display continue.

Reads a bounded session/runtime/terminal-bound display projection under `~/.pi/loops`; never writes scheduler/process state. Watches atomic changes and uses native animation for fresh running processes.30s runtime heartbeat; after65s without runtime proof, read failure, shutdown or missing source terminal, durations/animation freeze and last snapshot is labeled. Temporary monitor output is latest3 logical captured lines, wrapped, not a durable log or worker transcript. Use existing `/monitors` in Pi for full temporary output/actions. No native process actions or progress/monitor numbering.

Uses semantic Herdr colors and inherited font/zoom. The compact Pi status/footer defaults off; `/monitors compact-on` and `/monitors compact-off` control it in the running instance, while `PI_LOOP_MONITOR_TUI_STATUS=1` remains the startup opt-in default. No network calls or separate server. Install only these assets and the activity-aware personal Tasks header; never overwrite customized files silently. Its personal `mod.json` must declare `"pi_activity_header": 1`; updated Tasks creates this declaration for new header clones.
